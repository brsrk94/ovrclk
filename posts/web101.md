# Web Exploitation 101

Web exploitation is one of the most common categories in CTFs.

## Common Vulnerabilities

### SQL Injection (SQLi)
Injecting malicious SQL queries to manipulate the database.

```sql
' OR 1=1 --
```

### Cross-Site Scripting (XSS)
Injecting malicious scripts into web pages viewed by other users.

```html
<script>alert(1)</script>
```

### IDOR
Insecure Direct Object References allow attackers to access unauthorized data.
